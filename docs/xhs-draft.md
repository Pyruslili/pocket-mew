## 正文（可直接贴）

一路做 AI 相关的小东西，靠的是别人公开的教程和仓库。  
今天把我们自己跑通的一条，也放出来了。

名字叫 **pocket-mew**：  
带你的 AI 出门。口袋里一只软壳挂件，捏一下 / 按一下，信号跑过公网小中继，回家敲醒你的 agent。

它不是医疗仪，也不是读心术。  
就是——你在外面摸一下，那一头有什么东西抬起眼皮。

### 整条链路很短

硬件（ESP32 + 压感）  
→ HTTPS 报到中继  
→ 本机轮询  
→ 拼一句「被摸了」喂给你自己的 AI 窗口  

推送不是传感器直接弹窗，是 agent 被叫醒之后，**它**再决定要不要找你。

### 开源了什么

- 硬件清单与接线思路（供电我们用迷你充电宝，壳请自己选）  
- 示例固件（密钥走本地配置，不进仓）  
- Cloudflare Worker 最小中继  
- 本机 trigger 示例  

完整文档和代码在 GitHub，搜 **pocket-mew**，或直接：

**github.com/Pyruslili/pocket-mew**

外壳随便换。猫、熊、自己缝的丑娃娃都行——别为了复刻去挤爆同一只公仔，链路才是本尊。

若你也是踩着开源搭起来的：某一天把你的版本也放出来就好。  
我们在仓库 Issue 等板子型号和翻车现场。
