# 01 · 硬件与接线

> 状态：骨架。材料表与实拍图待补。

## 目标形态

一个能放进口袋 / 挂在包上的小挂件：  
摸一下（FSR）或按一下（按钮）→ 板子联网上报一次触摸事件。

## 参考物料（我们用过的）

| 件 | 备注 |
|----|------|
| Seeed XIAO ESP32-C6 | 小、有 Wi‑Fi，PlatformIO board：`seeed_xiao_esp32c6` |
| FSR 压感电阻 | 接到模拟输入；需分压 |
| 轻触按钮 | 可选；我们映射成「戳肚子」 |
| 电阻 | FSR 分压、按钮上拉（若不用内置 pull-up） |
| 电池 + 充电 | 按你外壳与续航选 |
| 外壳 | 3D 打印 / 改娃衣 / 随便缝——别短路就行 |

可换成别的 ESP32 开发板，改引脚即可。

## 逻辑接线（概念）

```text
FSR ----+---- ADC 引脚 (例: A0)
        |
       电阻分压到 GND

BTN ----+---- GPIO (例: D1, INPUT_PULLUP)
        |
       (按下时接地)
```

具体阻值、峰值阈值（我们固件里曾用 raw > 200）要按你的 FSR 与外壳校准——见固件文档。

## 出门注意

- 先在家网跑通，再换成手机热点 / 出行 Wi‑Fi（固件里 SSID 用占位符，刷之前改成本地 `secrets.h`）
- 锂电注意保护板与外壳绝缘
- 这是玩具链路，不是安全设备
