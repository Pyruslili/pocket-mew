# 05 · 安全与边界

## 绝对不要公开的

- Wi‑Fi SSID / 密码  
- Worker 鉴权 token  
- 推送证书、APNs key、设备 token  
- 私人域名上的管理接口  
- 任何「一键登录我家」的配置  

## 仓库卫生

- 用 `secrets.h.example` / `.env.example`，真文件 gitignore  
- 若曾经 push 过密钥：视为泄漏 → **轮换**，并考虑清 git 历史  
- fork 自家魔改脑、伴侣 App、内网文档 → 用 **private** 仓

## 产品边界

- pocket-mew 是触达玩具，不是心率/医疗设备  
- 曲线与 peak 是力学近似，不是情感测量仪  
- 文案可以可爱，别冒充科学结论

## 对 AI 侧的诚实

摸摸是外部事件。  
模型是否「感受到」、要不要回你，是 agent 自己的事；  
硬件只负责把「发生过一次触碰」送到。

## 许可与再分发

MIT。改完再开源时，请继续不要夹带你的家钥。  
我们开源的是链路，不是钥匙串。
